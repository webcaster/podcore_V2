Eigene PodCore-Lizenz-API mit WooCommerce-Abos, Code-Generator und offline signierten Lizenzdokumenten.

== Beschreibung ==

PodCore Licensing for WooCommerce erzeugt PodCore-Lizenzen aus WooCommerce-Bestellungen und verarbeitet Verlängerungen aus WooCommerce Subscriptions. Unterstützt werden Monatsabo, Jahresabo und Sonderabo. Lizenzen können über die PodCore-App online aktiviert oder als signiertes Dokument offline importiert werden.

== Installation ==

1. Plugin hochladen und aktivieren.
2. WooCommerce aktivieren.
3. PodCore-Produkte konfigurieren.
4. In PodCore unter Einstellungen > Lizenzierung verbinden oder ein Offline-Dokument importieren.

== Datenschutz ==

Das Plugin speichert Lizenz- und Bestellmetadaten in der WordPress-Datenbank. Private Signaturschlüssel werden nicht über REST ausgegeben. API-Zugangsdaten werden nicht in Lizenzdokumenten gespeichert.
