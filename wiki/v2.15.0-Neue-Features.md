## 🎨 Light-Mode Design

### Aktivierung
1. Klicken Sie auf **Einstellungen** (Zahnrad-Icon oben rechts)
2. Navigieren Sie zum Tab **"Mein Design"**
3. Unter **"Farbschema"** wählen Sie zwischen:
   - 🌙 **Dunkles Design** (Standard)
   - ☀️ **Helles Design** (Neu in v2.15.0)

### Funktionsweise
- Das gewählte Theme wird sofort angewendet
- Ihre Wahl wird automatisch gespeichert
- Beim nächsten Login wird das gespeicherte Theme automatisch geladen
- Das Light-Mode funktioniert mit allen Accent-Farben

### Light-Mode Farben
| Element | Farbe | Hex-Code |
|---------|-------|----------|
| Hintergrund | Weiß | #ffffff |
| Oberflächen | Hellgrau | #f0f1f3 |
| Text (Primär) | Dunkelgrau | #111827 |
| Text (Sekundär) | Grau | #6b7280 |
| Rahmen | Hellgrau | #d1d5db |

## 🗑️ Kaskadierendes Löschen & Papierkorb

### Neue Funktionen
Mit v2.15.0 können Sie Ideenmappen sicher löschen:

#### Papierkorb (Soft Delete)
- Ideenmappen gehen in den Papierkorb
- Alle Daten bleiben erhalten
- Wiederherstellung jederzeit möglich
- Automatische Löschung nach 30 Tagen (optional)

#### Permanentes Löschen
- Ideenmappe wird vollständig gelöscht
- ALLE verknüpften Daten werden gelöscht:
  - Checklisten
  - Notizen
  - Dateien (physisch vom Server)
  - Interviewpartner-Verknüpfungen
- **Keine Wiederherstellung möglich!**

### Workflow
1. Ideenmappe auswählen
2. Auf "Löschen" klicken
3. Wählen zwischen:
   - 📁 **In Papierkorb** (empfohlen)
   - 🗑️ **Permanent löschen** (Vorsicht!)
4. Bestätigen

### Papierkorb wiederherstellen
1. Gehen Sie zu **Redaktions-Hub → Papierkorb**
2. Wählen Sie die Ideenmappe
3. Klicken Sie auf **"Wiederherstellen"**
4. Ideenmappe ist wieder verfügbar

## ✅ Freigabeanfragen & Benachrichtigungen

### Neue Funktionalität
Mit v2.15.0 können Sie Episoden und Interview-Fragen zur Genehmigung anfordern:

### Episoden-Freigabe
1. **Freigabe anfordern:**
   - Gehen Sie zur Episode
   - Klicken Sie auf **"Zur Freigabe anfordern"**
   - Optionale Nachricht hinzufügen
   - Senden

2. **Genehmigung durch Moderator/Admin:**
   - Benachrichtigung im Notification Center
   - Klicken Sie auf die Benachrichtigung
   - Genehmigen oder Ablehnen
   - Optional: Kommentar hinzufügen

3. **Status-Verfolgung:**
   - Redakteur sieht Status der Anfrage
   - Benachrichtigung bei Genehmigung/Ablehnung

### Interview-Fragen-Freigabe
Gleicher Workflow wie bei Episoden:
1. Frage zur Freigabe anfordern
2. Moderator/Admin genehmigt/lehnt ab
3. Redakteur wird benachrichtigt

### Benachrichtigungen
- 🔔 Automatische Benachrichtigungen an Genehmiger
- 📧 Benachrichtigungen im Notification Center
- ✅ Status-Updates für Anfragensteller

## 🔒 Sichere Auto-Updates

### Neues Sicherheitssystem
v2.15.0 führt ein Elevation-Token System für Updates ein:

### Update-Prozess
1. **Admin fordert Elevation-Token an:**
   - Einstellungen → Update
   - Klicken Sie auf **"Elevation-Token anfordern"**
   - Token wird generiert (5 Minuten gültig)

2. **Update durchführen:**
   - Wählen Sie die Update-Datei
   - Geben Sie den Elevation-Token ein
   - Klicken Sie auf **"Update anwenden"**

3. **Anwendung wird neu gestartet:**
   - Update wird installiert
   - Anwendung startet neu
   - Neue Version ist aktiv

### Sicherheitsfeatures
- ✅ One-Time Tokens (nur einmalig verwendbar)
- ✅ 5 Minuten Gültigkeitsdauer
- ✅ Nur für Administratoren
- ✅ Verhindert versehentliche Updates

## 📄 PDF-Export für Interviewpartner

### Neue Features
Der PDF-Export wurde erweitert:

### Benutzerdefinierten PDF-Namen setzen
1. Gehen Sie zu **Redaktions-Hub → Interview-Partner**
2. Wählen Sie einen Partner
3. Klicken Sie auf **"PDF exportieren"**
4. Geben Sie einen benutzerdefinierten Namen ein
5. PDF wird mit Ihrem Namen erstellt

### Episode verknüpfen
1. Wählen Sie einen Interview-Partner
2. Klicken Sie auf **"PDF exportieren"**
3. Wählen Sie die zugehörige Episode
4. Episode-Informationen werden im PDF angezeigt

### Personalisierte Begrüßung
1. Geben Sie eine eigene Begrüßungsnachricht ein
2. Diese wird statt der Standard-Nachricht verwendet
3. PDF wird mit Ihrer Nachricht erstellt

### Beispiel-Workflow
```
Partner: Max Mustermann
Episode: #42 - Podcast-Produktion
Dateiname: Interview-Max-Mustermann-Folge-42
Begrüßung: "Lieber Max, vielen Dank..."
```

## 🔧 Backup & Restore

### Reparierte Funktionen
v2.15.0 behebt Fehler im Backup/Restore-System:

### Backup erstellen
1. Gehen Sie zu **Einstellungen → Backup & Restore**
2. Klicken Sie auf **"Vollständiges Backup erstellen"**
3. Alle Daten werden exportiert (ZIP-Datei)
4. Datei wird heruntergeladen

### Backup wiederherstellen
1. Gehen Sie zu **Einstellungen → Backup & Restore**
2. Klicken Sie auf **"Backup importieren"**
3. Wählen Sie die ZIP-Datei
4. **Wichtig:** Ein Backup der aktuellen Daten wird automatisch erstellt
5. Daten werden wiederhergestellt

### Was wird gesichert?
- ✅ Alle Ideenmappen
- ✅ Alle Episoden
- ✅ Alle Sponsoren
- ✅ Alle Interview-Partner
- ✅ Alle Interview-Fragen
- ✅ Redaktionsplan
- ✅ Alle Einstellungen

## 📝 Entfernte Funktionen

### Was wurde entfernt?
Mit v2.15.0 wurden zwei veraltete Funktionen entfernt:

| Funktion | Grund | Alternative |
|----------|-------|-------------|
| HTML-Zusammenfassung | Veraltet | PDF-Export |
| Per Mail senden | Zu begrenzt | PDF + Email-Client |

### Migration
**Alte Methode:**
```
GET /interviews/partners/:id/send-summary
POST /interviews/partners/:id/send-email
```

**Neue Methode:**
```
GET /interviews/partners/:id/export-pdf
→ PDF mit Ihrem Email-Client versenden
```

## ❓ Häufige Fragen

**F: Kann ich zwischen Light und Dark Mode wechseln?**  
A: Ja, jederzeit in den Einstellungen unter "Mein Design"

**F: Wird meine Theme-Wahl gespeichert?**  
A: Ja, sie wird gespeichert und beim nächsten Login automatisch geladen

**F: Kann ich gelöschte Ideenmappen wiederherstellen?**  
A: Ja, wenn Sie sie in den Papierkorb verschoben haben. Permanent gelöschte Ideenmappen können nicht wiederhergestellt werden.

**F: Wie funktioniert das Elevation-Token System?**  
A: Der Admin fordert einen One-Time Token an, der 5 Minuten gültig ist. Mit diesem Token kann das Update durchgeführt werden.

**F: Kann ich die alte Email-Funktion noch verwenden?**  
A: Nein, diese wurde entfernt. Verwenden Sie stattdessen den PDF-Export und Ihren Email-Client.

**F: Werden meine Daten beim Backup gesichert?**  
A: Ja, alle Daten werden gesichert und können wiederhergestellt werden.
